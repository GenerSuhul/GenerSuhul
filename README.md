## 🏗️ Selected engineering work

### ✈️ Airport Platform — DevOps / SRE / Kubernetes
**[`proyectoFinalSistemasOperativosII`](https://github.com/GenerSuhul/proyectoFinalSistemasOperativosII)**

An end-to-end enterprise-style airport platform with **Java 21 + Spring Boot 3, Angular, Oracle Database 23ai, Docker, Kubernetes, NGINX Ingress, Prometheus, Grafana, HPA and GitHub Actions**. Includes authentication, reservations, ticketing, admin workflows, observability, health probes, automated deployment scripts, backups, runbooks and failure simulation.

`Java` `Spring Boot` `Angular` `Oracle` `Docker` `Kubernetes` `Prometheus` `Grafana` `CI/CD` `SRE`

---

### 🌎 AeroPulse Live — Real-time aircraft monitoring
**[`aeropulse-live`](https://github.com/GenerSuhul/aeropulse-live)**

Real-time aircraft visualization built with **Angular + TypeScript + MapLibre**, consuming live aviation sources with fallback handling, interpolation between updates and a serverless production proxy on Vercel. The project is intentionally designed around **real data, graceful degradation and production-safe behavior instead of fabricated mock metrics**.

`Angular` `TypeScript` `MapLibre` `RxJS` `Tailwind` `Serverless` `Vercel` `Real-time APIs`

---

### 🕒 Hikvision Attendance Control — Device integration platform
**[`time-and-asistant`](https://github.com/GenerSuhul/time-and-asistant)**

A production-minded monorepo for attendance and access-control integration. Architecture connects **Hikvision devices → Node.js/TypeScript Device Gateway → Supabase PostgreSQL / Edge Functions → React application**, with shared types, RLS, environment separation, historical synchronization and safeguards that prevent demo data from contaminating production.

`React` `TypeScript` `Node.js` `Supabase` `PostgreSQL` `Edge Functions` `Device Gateway` `Linux / PM2`

---

### 📊 HikCentral Reports — Operational reporting UI
**[`hikcentral-reports`](https://github.com/GenerSuhul/hikcentral-reports)**

Reporting and operational tooling using **React, Material UI, Supabase and XLSX**, with modern UI components, data grids, animations and database migration tooling.

`React` `Material UI` `Supabase` `JavaScript` `XLSX` `Framer Motion`

## 🏢 Enterprise & integration mindset

My work goes beyond CRUD applications. I enjoy the parts where software has to interact with the real world:

- **Enterprise systems:** SAP Business One, SAP HANA, Service Layer and business-process integration.
- **Integration architecture:** middleware, REST APIs, synchronization workers, edge/serverless functions and device gateways.
- **Data:** PostgreSQL, SQL Server, Supabase, Oracle and relational data modeling.
- **Infrastructure:** Linux VPS, Docker, Kubernetes, reverse proxies, Cloudflare, Vercel and self-hosted services.
- **Reliability:** observability, health checks, metrics, alerts, backups, recovery workflows and operational documentation.
- **Security-minded delivery:** environment separation, secret handling, RLS/least privilege, secure mail transport configuration and production-safe defaults.
